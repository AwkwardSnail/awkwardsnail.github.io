aWkward sn@ail

Calm, simple tools that stay the way you left them.

aWkward sn@ail makes small, sensory-friendly software. Each app does one job, quietly, without clutter, noise or surprises.

> our promise

  1. Minimal. Clutter-free apps that do the basics well. No notifications, no nagging, no flashing, no streaks or badges.
  2. Stays put. No redesigns and no removed features. Updates only fix bugs and improve what is already there, so you never have to ask “where did that go?”.
  3. Honest price. Low price you pay only once. No subscriptions, no in-app purchases, no ads. Once you buy it, it is yours.
  4. Open source. All source code is on GitHub. If you are happy to compile it yourself, it is free. The price pays for the convenience of a ready-made build with automatic updates.
