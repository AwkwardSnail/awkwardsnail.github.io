aWkward sn@ail

Calm, simple tools that stay the way you left them.

aWkward snail makes small, sensory-friendly software. Each app does one job, quietly, without clutter, noise or surprises.

> our promise

  1. Minimal. Clutter-free apps that do the basics well. No notifications, no nagging, no flashing, no streaks or badges.
  2. Stays put. No redesigns and no removed features. Updates only fix bugs and improve what is already there, so you never have to ask “where did that go?”.
  3. Honest price. Low price you pay only once, and some apps are free for personal use. No subscriptions, no in-app purchases, no ads. Once you have it, it is yours. If a business or organisation uses one of our free apps, we ask for a site licence: email hello@awkwardsnail.com.au. This is a request, not a condition of use.
    P.S. We donate 10% of all sales proceeds to Wikipedia and Archive.org to help fight for a less cluttered internet.
  4. Open source. All source code is on GitHub. If you are happy to compile it yourself, it is free. The price pays for the convenience of a ready-made build with automatic updates.

> apps

  • Chain Calc free

    A calculator laid out like a tiny spreadsheet. Five cells, each with its own operation, and the running result shown at every step. For Windows.

    Get it from the Microsoft Store · Source code on GitHub

  • Simple Music Melody A$1.50

    Write your notes first, count the bars later. A simple music editor that divides your melody into bars for you, with playback, lyrics, and PDF and MIDI export. For Windows.

    Get it from the Microsoft Store · Source code on GitHub

  • SimpleLetters free

    A plain word processor: one A4 page, and you write on it. The only things you can change are the margins and the font size. For Windows.

    Get it from the Microsoft Store · Source code on GitHub

  • SimpleLetters Fun A$1.50

    Write letters in your own handwriting. Draw any letter on squared paper and everything you type uses your drawing. For children 8 and up. For Windows.

    Get it from the Microsoft Store · Source code on GitHub

  • Simple Web Text Browser free

    A web browser that shows only the text of a page, with the look of a 1980s computer terminal. No pictures, no video, no adverts, just words and links. For Windows.

    Get it from the Microsoft Store · Source code on GitHub

  • SimplePDF Editor

    Change a PDF without spoiling the rest of the page. Rewrite a paragraph and its words wrap again; move, turn, restyle or delete text, shapes and pictures. For Windows.

    Get it from the Microsoft Store · Source code on GitHub
